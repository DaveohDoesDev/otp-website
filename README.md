# Over The Top Party Rentals: Website

Website for **Over The Top Party Rentals**, a party rental company in Culpeper, VA. Built by [Built by Laird](https://daveohdoesdev.github.io/built-by-laird/).

> **Demo site.** The contact form isn't connected yet; see `SETUP.md` to hook it up.

**Live:** https://daveohdoesdev.github.io/otp-website/

## What's here

| Path | Contents |
|---|---|
| `index.html` | The whole site (one page) |
| `styles.css`, `script.js` | Styles and interactions |
| `images/` | Photos and graphics |
| `SETUP.md` | How to connect the contact form (Web3Forms) |

## Updating

Push to `main`, and GitHub Pages republishes the site within a minute or two. To preview locally, run `python3 -m http.server 8000` and open http://localhost:8000.
